# One Piece: Character Presentation
This project aims to provide a detailed overview of the characters from the One Piece universe, the popular anime and manga series created by Eiichiro Oda. Here, you'll find information about the Straw Hat Pirates.


## Project Structure
The project is organized to make it easy to navigate through the different characters and their respective information. Each character is presented with details such as:
1. Name
2. Abilities
3. Affiliation (such as their crew or organization)
4. Image
5. Description


## Technologies Used
Frontend: HTML, CSS, JavaScript
